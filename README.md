# AdsVideoMaker — рекламные ролики за 10 минут

Клиент выбирает «Приложение / Товар / Услуга», вставляет ссылку и нажимает «Сделать видео».
Получает 3 версии ролика (разные начала) для TikTok, Reels и Shorts с описаниями и обложкой,
может поправить текст сцены, перерисовать картинку или поставить своё фото и пересобрать ролик.

Оплата — **рубины 💎** через Stripe, как в SnapDance. Ключи fal.ai и Stripe хранятся только на сервере.

## Файлы

| Файл | Что это |
|---|---|
| `server.js` | сервер: прокси fal.ai, рубины, оплата Stripe, админка |
| `public/index.html` | сайт для клиента |
| `public/admin.html` | админка: `/admin` |
| `package.json` | зависимости |

## Запуск на Railway

1. Проект создаётся из этого репозитория (New Project → Deploy from GitHub repo).
2. **Volume** (обязательно — там рубины клиентов и заказы): правый клик по пустому месту → **Volume** → сервис → путь `/data`.
   Сервер сам находит диск Railway, отдельная переменная не нужна.
3. **Settings → Networking → Generate Domain** — адрес сайта.
4. **Variables**:

| Переменная | Значение |
|---|---|
| `FAL_KEY` | ключ fal.ai |
| `ADMIN_PASSWORD` | пароль для `/admin` |
| `STRIPE_SECRET_KEY` | `sk_live_…` (для теста `sk_test_…`) — Stripe → Developers → API keys |
| `STRIPE_PUBLISHABLE_KEY` | `pk_live_…` (для теста `pk_test_…`) — там же |
| `STRIPE_WEBHOOK_SECRET` | `whsec_…`, см. ниже |
| `PUBLIC_URL` | адрес сайта из шага 3, например `https://adsvideomaker.up.railway.app` (без `/` в конце) |
| `STUDIO_NAME` | (по желанию) название в оплате и админке |

5. **Вебхук Stripe** — чтобы рубины начислялись, даже если клиент закрыл страницу сразу после оплаты:
   Stripe → Developers → Webhooks → **Add endpoint**
   - URL: `https://ВАШ-АДРЕС/api/stripe/webhook`
   - события: `checkout.session.completed` и `checkout.session.async_payment_succeeded`
   - **Signing secret** скопируйте в `STRIPE_WEBHOOK_SECRET`.
6. Проверка: `https://ВАШ-АДРЕС/api/health` — должно быть «ключ принят», Stripe «подключён», хранилище «сохраняется».

## Первые шаги

- `/admin` → «Коды клиентов» → создайте себе код, например на 1000 рубинов. Откройте ссылку, которую покажет админка
  (`https://ВАШ-АДРЕС/?key=AV-…`), — и делайте ролики со своего баланса.
- Тестовая оплата: тестовые ключи Stripe и карта `4242 4242 4242 4242`, любая будущая дата, любой CVC.
  Потом замените ключи на боевые `sk_live_…` / `pk_live_…`.

## Как считаются цены

`/admin` → «Пакеты и цены»: цена в рубинах считается **автоматически** = себестоимость fal.ai × наценка
(по умолчанию ×3 + 10% запаса на неудачные генерации). Рубин оценивается по самому выгодному пакету за вычетом
комиссии Stripe (4% + 0,30 с запасом) и НДС, если он есть, — поэтому наценка соблюдается при любом пакете.
Внизу — таблица-проверка: сколько платит клиент, сколько остаётся вам и реальная наценка.

По умолчанию: ролик «Премиум» 💎 156, «Быстрый» 💎 50, перерисовать сцену 💎 5, пересобрать ролик 💎 13.
Пакеты: 💎 200 — 19,99 €, 💎 500 — 44,99 €, 💎 1500 — 119,99 €.

- Если вы плательщик НДС/IVA и цены пакетов его включают — впишите ставку (например, 21) в «НДС / IVA в цене».
- Если fal.ai поменяет цены — обновите себестоимость действий там же, рубины пересчитаются сами.

## Как работает для клиента

1. Вставляет ссылку, выбирает язык и качество, нажимает «Сделать видео — 💎 156».
2. Если рубинов нет — прямо на странице открывается выбор пакета и оплата картой. Загруженные фото не теряются.
3. После оплаты сайт показывает личный код `AV-…` — по нему баланс доступен с любого устройства («У меня есть код»).
4. Если ролик не получился в самом начале (неверная ссылка и т.п.) — рубины возвращаются автоматически.
5. Сервер не даёт потратить в fal.ai больше, чем оплачено, — обойти оплату нельзя.
