# Сервис рекламных роликов

Клиент открывает страницу, выбирает «Приложение / Товар / Услуга», вставляет ссылку и нажимает «Сделать видео».
Через 5–10 минут получает 3 версии ролика (разные начала) для TikTok, Reels и Shorts, с описаниями и обложкой.
Можно поправить текст любой сцены, перерисовать картинку или поставить своё фото и пересобрать ролик.

Ключ fal.ai хранится только на сервере — клиенты его не видят и ничего не настраивают.

## Запуск на Railway (или любом хостинге с Node.js 18+)

1. Залейте папку в репозиторий GitHub и создайте проект на Railway из этого репозитория.
2. В Variables добавьте:
   - `FAL_KEY` — ваш ключ с https://fal.ai/dashboard/keys
   - `ACCESS_CODES` — коды для клиентов через запятую, например `anna2026,shop-ivan,test123`
3. Railway сам выполнит `npm install` и `npm start`. Откройте выданный адрес — это и есть сервис.

Каждому клиенту выдайте свой код. Чтобы закрыть доступ — уберите код из `ACCESS_CODES` и перезапустите.

## Локально

```
npm install
FAL_KEY=ваш_ключ ACCESS_CODES=test node server.js
```
Откройте http://localhost:3000

## Что важно

- Вся генерация оплачивается с вашего баланса fal.ai. Примерно: «Премиум» ≈ $3–4 за 3 версии, «Быстрее» ≈ $1–1.5.
  Следите за балансом в кабинете fal.ai и не оставляйте `ACCESS_CODES` пустым.
- Сервер пропускает к fal.ai только модели, которые нужны сервису (сценарий, картинки, видео, голос, музыка).
- Монтаж идёт в браузере клиента — лучше всего в Chrome или Edge на компьютере. Вкладку нельзя закрывать до конца.
