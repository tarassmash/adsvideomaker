# AdsVideoMaker — рекламные ролики за 10 минут

Клиент выбирает «Приложение / Товар / Услуга», вставляет ссылку и нажимает «Сделать видео».
Получает ролик до 15 секунд для TikTok, Reels и Shorts с описаниями и обложкой, может поделиться им,
поправить текст сцены, перерисовать картинку или поставить своё фото и пересобрать ролик.
Все ролики сохраняются в «Мои ролики». Новичкам — 3 ролика бесплатно.

Оплата — **кристаллы 💎** через Stripe, как в SnapDance. Ключи fal.ai и Stripe хранятся только на сервере.

## Файлы

| Файл | Что это |
|---|---|
| `server.js` | сервер: прокси fal.ai, кристаллы, оплата Stripe, админка |
| `public/index.html` | сайт для клиента |
| `public/admin.html` | админка: `/admin` |
| `public/privacy.html`, `public/terms.html` | политика конфиденциальности и условия использования |
| `package.json` | зависимости |

## Запуск на Railway

1. Проект создаётся из этого репозитория (New Project → Deploy from GitHub repo).
2. **Volume** (обязательно — там кристаллы клиентов, заказы, ролики и примеры): правый клик по пустому месту → **Volume** → сервис → путь `/data`.
   Сервер сам находит диск Railway, отдельная переменная не нужна.
3. **Settings → Networking → Generate Domain** — адрес сайта.
4. **Variables**:

| Переменная | Значение |
|---|---|
| `FAL_KEY` | ключ fal.ai |
| `ADMIN_PASSWORD` | пароль для `/admin` |
| `STRIPE_SECRET_KEY` | `sk_live_…` (для теста `sk_test_…`) — Stripe → Developers → API keys |
| `STRIPE_PUBLISHABLE_KEY` | `pk_live_…` (для теста `pk_test_…`) — там же |
| `STRIPE_WEBHOOK_SECRET` | `whsec_…`, см. ниже |
| `PUBLIC_URL` | адрес сайта из шага 3, например `https://adsvideomaker.up.railway.app` (без `/` в конце) |
| `STUDIO_NAME` | (по желанию) название в оплате, на сайте и в документах |
| `CONTACT_EMAIL` | почта поддержки — показывается в подвале, политике и условиях |
| `OWNER_NAME` | кто владелец сервиса для документов, например «Иван Иванов, autónomo, NIF X1234567Z» |
| `CLIP_DAYS` | (по желанию) сколько дней хранить ролики клиентов, по умолчанию 90 |

5. **Вебхук Stripe** — чтобы кристаллы начислялись, даже если клиент закрыл страницу сразу после оплаты:
   Stripe → Developers → Webhooks → **Add endpoint**
   - URL: `https://ВАШ-АДРЕС/api/stripe/webhook`
   - события: `checkout.session.completed` и `checkout.session.async_payment_succeeded`
   - **Signing secret** скопируйте в `STRIPE_WEBHOOK_SECRET`.
6. Проверка: `https://ВАШ-АДРЕС/api/health` — должно быть «ключ принят», Stripe «подключён», хранилище «сохраняется».

## Первые шаги

- `/admin` → «Коды клиентов» → создайте себе код, например на 1000 кристаллов. Откройте ссылку, которую покажет админка
  (`https://ВАШ-АДРЕС/?key=AV-…`), — и делайте ролики со своего баланса.
- Тестовая оплата: тестовые ключи Stripe и карта `4242 4242 4242 4242`, любая будущая дата, любой CVC.
  Потом замените ключи на боевые `sk_live_…` / `pk_live_…`.

## Как считаются цены

`/admin` → «Пакеты и цены»: цена в кристаллах считается **автоматически** = себестоимость fal.ai × наценка
(по умолчанию ×3 + 10% запаса на неудачные генерации). Кристалл оценивается по самому выгодному пакету за вычетом
комиссии Stripe (4% + 0,30 с запасом) и НДС, если он есть, — поэтому наценка соблюдается при любом пакете.
Внизу — таблица-проверка: сколько платит клиент, сколько остаётся вам и реальная наценка.

По умолчанию: ролик «Премиум» 💎 156, «Быстрый» 💎 50, перерисовать сцену 💎 5, пересобрать ролик 💎 13.
Пакеты: 💎 200 — 19,99 €, 💎 500 — 44,99 €, 💎 1500 — 119,99 €.

- Если вы плательщик НДС/IVA и цены пакетов его включают — впишите ставку (например, 21) в «НДС / IVA в цене».
- Если fal.ai поменяет цены — обновите себестоимость действий там же, кристаллы пересчитаются сами.

## Как работает для клиента

1. Вставляет ссылку, выбирает язык и качество, нажимает «Сделать видео — 💎 156».
2. Если кристаллов нет — прямо на странице открывается выбор пакета и оплата картой. Загруженные фото не теряются.
3. После оплаты сайт показывает личный код `AV-…` — по нему баланс доступен с любого устройства («У меня есть код»).
4. Если ролик не получился в самом начале (неверная ссылка и т.п.) — кристаллы возвращаются автоматически.
5. Сервер не даёт потратить в fal.ai больше, чем оплачено, — обойти оплату нельзя.

## Бесплатные ролики, история, примеры

- **Подарок новичку.** При первом входе — окно «3 ролика бесплатно». Подарок даётся один раз на интернет-адрес.
  Число бесплатных роликов меняется в `/admin` → «Пакеты и цены» (0 — выключить подарок).
- **История.** Каждый готовый ролик сохраняется на Volume и виден в «Мои ролики» по личному коду с любого устройства.
  Через `CLIP_DAYS` дней (по умолчанию 90) ролики удаляются сами. Один ролик ≈ 10–12 МБ.
- **Поделиться.** На телефоне кнопка отправляет сам видеофайл в любое приложение, на компьютере копирует ссылку
  на страницу ролика `/v/…` с плеером и кнопкой «Сделать такой же ролик».
- **Примеры на главной.** `/admin` → «Примеры на главной»: загрузите MP4 или нажмите «⭐ В примеры» у ролика клиента
  во вкладке «Ролики». Порядок, подпись, скрыть и удалить — там же. Показывайте ролики клиентов только с их согласия.
- **Документы.** `/privacy` и `/terms` — подставьте `OWNER_NAME` и `CONTACT_EMAIL`. Тексты — хорошая основа,
  но перед запуском рекламы их стоит показать юристу или гестору.
