# Сервис рекламных роликов

Клиент открывает страницу, выбирает «Приложение / Товар / Услуга», вставляет ссылку, оплачивает картой
и получает 3 версии ролика (разные начала) для TikTok, Reels и Shorts, с описаниями и обложкой.
Потом можно поправить текст сцены, перерисовать картинку или поставить своё фото и пересобрать ролик.

Ключи fal.ai и Stripe хранятся только на сервере.

## Как устроена оплата

- Цена = примерная себестоимость в fal.ai × `MARKUP` (по умолчанию ×3).
  По умолчанию: Премиум **13,50 €**, Быстрый **4,50 €**, пополнение на правки **3,00 €**.
- Оплата встроена прямо в страницу (Stripe Checkout). После оплаты у клиента появляется баланс.
- Сервер списывает с баланса реальную себестоимость каждого вызова нейросети (сценарий, картинка, видео, голос, музыка).
  Если вызов не прошёл — списанное возвращается. Остаток идёт на правки; если не хватает — клиент пополняет.
- Код из `ACCESS_CODES` даёт работу без оплаты — для вас и ваших тестов.

## Запуск на Railway

1. Проект создаётся из этого репозитория на GitHub.
2. В **Variables** добавьте:
   - `FAL_KEY` — ключ с https://fal.ai/dashboard/keys
   - `STRIPE_SECRET_KEY` — секретный ключ `sk_live_…` (для теста `sk_test_…`) с https://dashboard.stripe.com/apikeys
   - `STRIPE_PUBLISHABLE_KEY` — публичный ключ `pk_live_…` (для теста `pk_test_…`)
   - `ACCESS_CODES` — ваш код для бесплатной работы, например `owner-2026`
3. **Важно — постоянный диск для балансов.** В сервисе: правый клик → **Attach Volume**, путь `/data`.
   Затем добавьте переменную `DATA_DIR=/data`. Без этого после каждого обновления балансы клиентов
   восстанавливаются из Stripe как полные (клиенту на пользу, вам — небольшой убыток).

Необязательные настройки:

| Переменная | По умолчанию | Что это |
|---|---|---|
| `MARKUP` | `3` | Наценка к себестоимости |
| `CURRENCY` | `eur` | Валюта оплаты |
| `COST_PREMIUM` | `4.5` | Себестоимость премиум-ролика в $ (с запасом на правки) |
| `COST_STD` | `1.5` | Себестоимость быстрого ролика в $ |
| `COST_TOPUP` | `1` | Себестоимость пополнения на правки в $ |
| `PUBLIC_URL` | адрес запроса | Адрес сайта для возврата после 3-D Secure |

## Проверка оплаты

Сначала поставьте тестовые ключи Stripe (`sk_test_…`, `pk_test_…`) и оплатите картой `4242 4242 4242 4242`,
любая будущая дата и любой CVC. Когда всё работает — замените на боевые ключи `sk_live_…` и `pk_live_…`.

## Локально

```
npm install
FAL_KEY=… STRIPE_SECRET_KEY=sk_test_… STRIPE_PUBLISHABLE_KEY=pk_test_… node server.js
```
Откройте http://localhost:3000
